# MyFutureTens Android App

Official Android application for MyFutureTens.

MyFutureTens provides a simple mobile experience for registered users to access their dashboard, available tasks, account activity, referrals, and other platform features.

## Download Android App

Download the latest official APK from the **Releases** section of this repository.

## Installation

1. Download the latest MyFutureTens APK.
2. Open the downloaded APK on your Android phone.
3. Allow installation from this source if Android asks for permission.
4. Install and open MyFutureTens.
5. Sign in with your MyFutureTens account.

## Security

Only download MyFutureTens from the official links published by MyFutureTens. Never share your password, OTP, or other sensitive account information with anyone.
